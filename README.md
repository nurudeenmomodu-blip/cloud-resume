# Cloud Resume Challenge

This is my Cloud Resume Challenge project, built to demonstrate foundational cloud engineering skills on AWS.

## Technologies Used

- **AWS**: S3, CloudFront, Route 53, Lambda, API Gateway, DynamoDB
- **Infrastructure as Code**: Terraform
- **CI/CD**: GitHub Actions
- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Python (Lambda function)

## What This Project Does

- Hosts my resume as a static website on AWS S3
- Uses CloudFront for HTTPS and content delivery
- Includes a visitor counter that tracks views using Lambda and DynamoDB
- Entire infrastructure is provisioned using Terraform
- CI/CD pipeline automates deployments

## What I Learned

- Provisioning cloud resources using Infrastructure as Code
- Building serverless applications with AWS Lambda and API Gateway
- Automating deployments with CI/CD pipelines
- Troubleshooting IAM permissions and Lambda execution errors
